# 引用

给变量起别名

引用必须初始化

引用一旦初始化就不能更改

==考虑的是内存==

## 引用做函数的返回值

1. 函数的调用可以作为左值

   如果函数的返回是引用，那么函数调用可以用作左值

2. 不要返回局部变量的引用

## 引用的本质

在C++内部实现是一个指针常量

```c++
int a = 10;

int& ref = a;//自动转换为int* const ref = &a

ref = 20;//发现是引用之后 转换为*ref = 20
```

## 引用常量

1. 常量引用

   用来修饰形参，防止误操作

   ```c++
   void showValue(const int &val)
   ```

## 交换函数

1. 值传递

   不会改变实参，改变形参

2. 地址传递

   会改变实参

3. 引用传递

   形参会修饰实参
